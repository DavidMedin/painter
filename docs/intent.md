# Project Brief
This file is Read-only for agents.

## Purpose

Create painting software.

## Users
Artists that what an highly flexible painting program. Those who like tinkering with the engine of the tools.
## Non-goals
For now, only MacOS is supported. So, non-goals are support for Windows, Linux, Android, and iOS. Though, they will be supported eventually.
## Scope
High-level features this painting program will support.
- File I/O: loading files, writing to files, saving files, etc.
- Drawing and painting on a canvas.
  - highly configurable node-based brush system.
  - highly configurable node-based composition/layer system.
  - Non-destructive editing - all strokes are editable later.
- Multiplayer file editing - multiple users, over the network, editing the same document.
- Precise color control.
- headless support - editing files are possible without an actual screen, or on the terminal.
- Highly-configurable user interface.
- Highly accessible and innovative user interface.
  - Highly discoverable features.
