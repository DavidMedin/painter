## Requirements
KEY-1 - The system shall allow the user to change any keybind.
KEY-2 - The keybinds can be configured in the settings user interface.

KEY-3 - The default keybinding is as such:
- two finger drag on canvas => pan canvas
- two finger rotate on canvas => rotate canvas
- two finger scale on canvas => scale canvas
- stylus draw => draws
- stylus button 1 => toggle eraser
- stylus button 2 => color picker
- Help action => F1
