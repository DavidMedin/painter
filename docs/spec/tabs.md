# Tabs

The system shall associate tabs with open documents.
Along the toolbar of the application window will be tabs, one for each document that is open.
Each tab shall have an 'x' button on its left side that closes the tab and the document associated with it.
The system shall allow the tabs to be reordered by dragging some tab to some other spot (typical tab behavior in every app imaginable).
There is always one tab active.
The document that correlates with the currently active tab is the currently active document.
