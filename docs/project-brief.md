# Project Brief

## Purpose

Create painting software using Flutter and Dart.

## Confirmed Scope

- Flutter/Dart is the intended application technology.
- macOS is the current target.
- Linux, Windows, and Android are future targets. Their rollout order is undecided.

At the start of this initial documentation setup, the repository contained no application source or project documentation. These files establish its initial project documentation; no application source has been added. This repository is an Oh My Pi LLM harness.
