# Node Graph Composition: Behavior

Product direction for composing a painting from nodes instead of conventional layers. This system is a target and is not implemented; no design decision has been made, so there is no design document. Notation: [EARS+](../README.md#requirement-notation-ears). Related research (advisory, not a decision): [brush node-graph routes report](../../brush-node-graph-routes.typ).

## Composition

- **PNT-KIL-004** The Painter shall not provide conventional layers.
  Source: project owner.
- **PNT-KIL-005** The Painter shall allow canvas nodes to be layered, modified, and connected to a render/output node.
  Source: project owner.
- **PNT-KIL-006** WHEN the user selects a node, the Painter shall show that node's output in a preview.
  Source: project owner.
- **PNT-KIL-007** The Painter shall make the selected canvas node editable in the Canvas window.
  Source: project owner.
