# Task Backlog

[`ROADMAP.md`](ROADMAP.md) is the single canonical backlog. Keep all task records there; do not create parallel task lists elsewhere.

## Required task fields

Every task entry must include:

- A unique ID and title.
- Priority: `P0` or `P1`.
- Status: `todo`, `in-progress`, `blocked`, or `done`.
- Dependencies: task IDs or `none`.
- An outcome.
- Observable acceptance criteria.

## Workflow

- Dependencies are prerequisites and must be `done` before the dependent task starts.
- Keep exactly one task `in-progress` at a time.
- Mark a task `blocked` only with a concrete missing prerequisite.
- Mark a task `done` only after every acceptance criterion is verified.
- Keep completed task records in the roadmap.
